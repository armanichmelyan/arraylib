# arraylib

Кроссплатформенная динамическая библиотека операций над массивом целых чисел (калькулятор массивов) на C++.

## Функции

| Функция | Результат |
|---|---|
| `arr_sum` | сумма элементов |
| `arr_max` | максимальный элемент |
| `arr_min` | минимальный элемент |
| `arr_average` | среднее арифметическое (`double`) |
| `arr_count_positive` | количество элементов больше нуля |
| `arr_count_negative` | количество элементов меньше нуля |
| `arr_count_zero` | количество нулей |
| `arr_product` | произведение элементов |
| `arr_median` | медиана (`double`), исходный массив не изменяется |

Все функции принимают указатель на первый элемент и размер массива:

```cpp
int arr_sum(const int* arr, std::size_t n);
```
